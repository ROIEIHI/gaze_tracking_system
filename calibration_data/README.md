# Calibration Data Directory

This directory contains the calibration data files generated by the gaze tracking system.

## File Naming Convention
- `calibration_data_YYYYMMDD_HHMMSS.csv` - Calibration data with timestamp

## Data Format
Each CSV file contains the following columns:
- `norm_x_L`, `norm_y_L` - Normalized left eye coordinates
- `norm_x_R`, `norm_y_R` - Normalized right eye coordinates  
- `yaw`, `pitch`, `roll` - Head pose angles
- `target_x`, `target_y` - Target screen coordinates

## Usage
- These files are automatically generated during the calibration process
- The system automatically uses the most recent calibration data for training
- Files in this directory are excluded from version control via .gitignore
